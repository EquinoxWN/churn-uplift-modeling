## What the numbers say (Analyze)

- **Targets met.** Telco AUC 0.844 (logistic) and 0.836 to 0.837 (gbm) against a target of 0.80;
  ECE after calibration 0.022 to 0.037 for all three bases against 0.05. Every learner's mean
  predicted uplift on Hillstrom lies inside the observed 95% interval for both arms. On synthetic
  data T and X correlate 0.72 to 0.81 with the true effect (target 0.7 in the tests).
- **Calibration is not free.** Logistic regression was already calibrated (ECE 0.013) and isotonic
  made it slightly worse (0.022, log loss 0.418 to 0.437): isotonic steps add variance on 5,282
  training customers. It helped gradient boosting (0.036 to 0.023) and fixed naive Bayes, whose raw
  mean prediction was 0.475 against a churn rate of 0.265 (correlated one-hot features counted as
  independent evidence). Hence [ADR 0003](../adr/0003-calibrate-by-cross-fitting-and-report-raw-too.md):
  report both.
- **The linear S-learner cannot rank customers.** With the treatment as one more input of a
  logistic regression, the offer shifts every customer's log-odds by the same amount, so the
  predicted uplift barely varies (correlation 0.04 with the truth). Trees (S with gbm, 0.93) or
  separate models per arm (T, X) are needed. A test pins this down.
- **Hillstrom has little heterogeneity to find.** The top 30% by predicted uplift shows +0.067 to
  +0.087 against +0.027 to +0.041 for the rest (women's e-mail), but the intervals overlap for all
  but the X-learner with gbm, and the ordering between learners is not stable across bases or arms.
  Telling learners apart on real data needs the Qini evaluation of M2.
- **Defects found and fixed while building** (root causes): (1) `smd` reported 1.4 for a feature
  that was constant in both arms, because floating-point rounding left a tiny non-zero variance and
  mean difference; spreads and gaps below 1e-9 of the feature's scale now count as zero. (2) The
  first synthetic campaign clipped probabilities at 0.01 and 0.99, so some planted effects silently
  became zero; the baseline is now bounded to 0.05 to 0.75 so every planted effect is exact.

## Improve and Control

- Improve: calibration lowers ECE where the base model is miscalibrated (gbm by 35%, naive Bayes by
  87%), and the randomization gate stops uplift runs on targeted data (abs(SMD) > 0.1).
- Control: CI runs `ruff`, `mypy --strict`, 84 tests (calibration against the true probability,
  learners against planted effects, worked-example metrics, malformed-file refusals), `pip-audit`,
  and both public-data runs with the results as `::notice` annotations (not yet run, see top).
  The datasets are refused unless their SHA-256 matches.

## Reproduce

```bash
make setup && make run     # downloads both files into data/ and prints the two tables above
cum uplift --arm mens      # the men's e-mail arm
cum uplift --synthetic     # known-truth run; add --base logistic for the second table
```

All runs are deterministic for a given seed (`--seed`, default 0). No model files are saved; models
live in memory for the run only, so nothing needs to be deleted afterwards.
